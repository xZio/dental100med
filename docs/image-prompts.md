# Картинки для сайта: что есть и что ещё нужно

Обновлено 09.09.2026 после редизайна по макету.

Палитра сайта: тёмно-синий `#124a6a`, синий `#287db6`, лёд `#e8f7fb`,
бирюза `#88edf0`, фон страниц `#e6f1f5`.

## Готово

- **Иконки разделов прайса** — 10 штук, 3D-стиль (белые зубы + бирюзовые
  инструменты), сгенерированы в ChatGPT, лежат в `public/images/services/<slug>.webp`.
  Появятся новые — класть туда же под тем же именем, код подхватит сам.
- **Картинка главного экрана** — 3D-сцена со стаканом и зубами из макета Codex,
  `public/images/hero-art.webp`.
- **Знак логотипа** — `public/images/logo-mark.png` (прозрачный, края вычищены).

Раньше в этом файле были промпты на плоские иконки «Почему выбирают нас»
и фоны секций — после редизайна этих блоков нет, промпты убраны.

## Нужно: интерьер клиники для блока «О клинике»

Куда: `public/images/clinic/interior-01.webp` (и `interior-02.webp`, если будет
второй кадр). Сейчас в блоке стоит `clinic-01.jpg` — врач с маленькой пациенткой.

Формат: **вертикальный 4:5**, не меньше 1200×1500. На сайте кадр показывается
590×700 со скруглёнными углами, поверх него в правом верхнем углу лежит
бирюзовый кружок-наклейка — правый верхний угол картинки лучше оставить спокойным.

К запросу приложить реальные снимки из `public/images/clinic/`, чтобы
сохранить узнаваемость оборудования: `clinic-04.jpg`, `clinic-16.jpg` (кабинеты),
`clinic-14.jpg` (ресепшн).

Промпт:

```
Вот реальные фотографии небольшой семейной стоматологии. Сделай на их основе
фотореалистичный вертикальный кадр (4:5) интерьера лечебного кабинета для сайта.

Сохранить: тип оборудования (стоматологическая установка с креслом, светильник,
столик с инструментами), ощущение небольшой уютной клиники, дневной свет из окна.

Изменить: интерьер современнее и спокойнее — светлые стены, много воздуха,
чистые ровные поверхности, никаких зелёных стен и розовых чехлов. Цветовые
акценты только холодные: голубой, бирюзовый, белый (как палитра сайта:
#287db6, #88edf0, #e8f7fb). Кресло пустое, людей в кадре нет.

Камера с уровня глаз, лёгкий ракурс три четверти, небольшая глубина резкости.
Освещение мягкое, естественное, без пересветов. Правый верхний угол кадра —
без важных деталей. Никакого текста, логотипов, водяных знаков.
```

Второй кадр (по желанию): та же формулировка, но ресепшн — стойка,
диван для ожидания, зелёное растение, вид от входа.

## Что сделать с готовыми картинками

1. Скинуть мне файлы — переведу в WebP, подрежу и поставлю в блок.
2. Если фон у иконок окажется не прозрачным, сниму его сам, как уже делал.
